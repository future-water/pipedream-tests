# pipedream-tests

Test cases:
- `hillslope_cliff`: A single hillslope terminating in an overflow.
- `ji`: Test network from original SUPERLINK paper.
- `extran1`: EXTRAN-1 network from SWMM quality assurance dataset.
- `user1`: USER-1 network from SWMM quality assurance dataset.
- `net2`: Net2 EPANET benchmark network.
- `ca1`: CA1 EPANET benchmark network.
- `pa1`: PA1 EPANET benchmark network.

Tests can be found as jupyter notebooks under the `notebooks` directory.

The `data` directory contains required input files and reference outputs.
